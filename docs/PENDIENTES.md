# Pendientes

## Antes de producción

- Crear un backup verificado de `PRODUCTOS_APP`.
- Revisar y ejecutar la limpieza de datos de prueba.
- Limpiar o archivar respaldos locales y archivos FTP de prueba según política operativa.
- Revisar el árbol Git, excluir secretos/runtime y crear un commit/tag estable.
- Completar una prueba mínima posterior a la limpieza.

## Mejoras no bloqueantes

- Ampliar pruebas de repositorios con una base aislada de integración.
- Incorporar almacenamiento persistente para sesiones si se despliega más de una instancia.
- Formalizar monitoreo y alertas de jobs/FTP.
